order
=====
This is a physics toy written in Javascript. It uses deformable body physics to animate a field of polygons.
After downloading, run by opening index.html in a browser.\
![Screenshot of "order" running](./screenshot.png)
You can generate shapes by clicking anywhere, then pressing a number key "3" through "9" for triangle through nonagon, "0" for decagon, or "f" for a random shape.
The gray tray to left can be opened and shapes cloned out.
Click on a shape and drag.
Resize the window.\
